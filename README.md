# 🎮 Sampa Link Hub

> Um gerenciador de favoritos gamer rápido, elegante e focado em privacidade, desenvolvido para centralizar links de emulação, ferramentas de consoles, ROMs e utilitários.

## ✨ Principais Funcionalidades

- **📂 Organização por Categorias:** Gerencie e filtre links facilmente com suporte a ícones personalizados e banners.
- **⚡ Importação em Massa:** Adicione dezenas de links de uma só vez colando uma lista ou importando um arquivo `.txt`.
- **🔒 Armazenamento 100% Local:** Seus favoritos ficam salvos no navegador (`localStorage`), garantindo total privacidade e velocidade.
- **🔄 Sistema de Atualização Automática:** Notificação integrada via `version.json` para avisar sempre que houver novas ferramentas adicionadas ao hub.
- **💾 Backup & Restauração:** Exporte e importe todos os seus dados e categorias em formato JSON com um único clique.
- **☕ Apoio ao Desenvolvedor:** Modal integrado com chave Pix (Copia e Cola) e QR Code direto para o Nubank.
